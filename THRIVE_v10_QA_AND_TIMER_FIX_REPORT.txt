- Browser-based local demo account creation uses Web Crypto; it must be tested on localhost or HTTPS rather than an opaque file/embedded origin.
- This is a personal-use prototype and has not been security-audited. Export a backup before replacing any deployed copy.

Suggested account test sequence
1. Export a backup of the current app data.
2. On the deployed HTTPS URL, create a disposable test account.
3. Confirm the email if enabled; sign out and sign back in.
4. Create a harmless task; refresh; confirm it remains.
5. Request password reset and complete the email flow.
6. Sign in on another device and verify that the same task appears.
7. Confirm the signed-in user cannot read or edit another test user's records.
8. Test offline edits and confirm sync status before relying on multi-device changes.
